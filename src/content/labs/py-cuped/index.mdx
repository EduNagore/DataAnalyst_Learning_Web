Los clientes asignados a `exp-onboarding-flow` (del 28 de octubre al 25 de noviembre de 2023) son la muestra. Como covariable previa usa los ingresos de los **90 días anteriores** al inicio (sin pedidos cancelados). Implementa:

1. **`ingresos_por_cliente(orders, order_items, clientes, inicio, fin)`** → array con los ingresos (sin cancelados) de cada cliente de `clientes` (en ese orden) entre `inicio` y `fin` ambos incluidos; 0 si no compró.
2. **`theta_cuped(x, y)`** → coeficiente $\theta = \operatorname{Cov}(X,Y)/\operatorname{Var}(X)$.
3. **`ajustar_cuped(y, x)`** → métrica ajustada $Y - \theta(X - \bar{X})$.
4. **`efecto_y_error(y, tratamiento)`** → `(diferencia, error_estandar)` tratamiento menos control (`tratamiento` es un array booleano), con el error estándar de Welch.
5. **`reduccion_varianza(x, y)`** → fracción de varianza que elimina el ajuste.

El script imprime el análisis real y una simulación con correlación 0,75.
