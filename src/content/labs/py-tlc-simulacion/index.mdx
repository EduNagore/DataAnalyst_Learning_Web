En el _starter_ tienes `importes`, un array con el importe de cada pedido no cancelado de Lumen (media 301,7 €, desviación 363,8 €).
Implementa:

1. **`medias_muestrales(x, n, reps, seed)`** → array de `reps` medias de muestras de tamaño `n` (con reemplazo), usando
   `np.random.default_rng(seed)`.
2. **`error_estandar_teorico(x, n)`** → `σ/√n` con la desviación de la población (2 decimales).
3. **`cobertura_ic(x, n, reps, seed)`** → porcentaje (1 decimal) de muestras de tamaño `n` cuyo intervalo
   `media ± 1,96·s/√n` contiene la media de `x`.

Comprueba que la desviación de las medias se parece al error estándar teórico y que la cobertura mejora con `n`.
