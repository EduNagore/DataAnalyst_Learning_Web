Calcula el importe de cada pedido no cancelado y el **gasto acumulado** de cada cliente por orden cronológico (`order_date`, `order_id`). Para cada cliente que llega a **1.000 €**, toma el **primer pedido** en el que el acumulado alcanza o supera esa cifra. Devuelve cuántos clientes lo logran en cada año de ese pedido.

**Formato del resultado:** `anio` y `clientes`.
