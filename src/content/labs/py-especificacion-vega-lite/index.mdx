En el _starter_ tienes `cuotas`: un DataFrame con las columnas `categoria` y `pct` (porcentaje de unidades vendidas en 2025 por
categoría de producto). Implementa:

1. **`espec_barras_ordenadas(df, categoria, valor, titulo)`** → un diccionario Vega-Lite (v6) con:
   - `$schema` de Vega-Lite v6, `title` igual a `titulo` y los datos en `data.values` (una lista de diccionarios),
   - `mark` de tipo `bar`,
   - `encoding.y`: la categoría, nominal, **ordenada de mayor a menor valor** (`sort: "-x"`),
   - `encoding.x`: el valor, cuantitativo, con el **eje empezando en cero** (`scale.domain[0] == 0` o `scale.zero == True`).
2. **`elegir_grafico(intencion, n_categorias=0)`** → el texto del gráfico recomendado:

   | `intencion`    | condición           | resultado                       |
   | -------------- | ------------------- | ------------------------------- |
   | `comparar`     | `n_categorias` ≤ 12 | `barras horizontales ordenadas` |
   | `comparar`     | `n_categorias` > 12 | `top N y otras`                 |
   | `tiempo`       | cualquiera          | `líneas`                        |
   | `distribucion` | cualquiera          | `histograma`                    |
   | `relacion`     | cualquiera          | `dispersión`                    |
   | `composicion`  | `n_categorias` ≤ 3  | `barra apilada al 100 %`        |
   | `composicion`  | `n_categorias` > 3  | `barras ordenadas`              |
   | `exacto`       | cualquiera          | `tabla`                         |

Cualquier otra intención debe lanzar `ValueError`. El título de tu gráfico debería concluir algo como
«Alimentación vende más unidades (13,5 %) y Moda menos (11,6 %)».
