Una **capa semántica** define las métricas **una sola vez** y genera el SQL de cualquier consulta a partir de esa definición. El diccionario `modelo` (ya escrito) describe la consulta base (cómo unir pedidos, líneas, productos y devoluciones), las dimensiones, las medidas y las métricas de Lumen.

Implementa:

1. **`expresion_metrica(modelo, nombre)`** → expresión SQL agregada de una métrica (simple, derivada o ratio), resolviendo otras métricas.
2. **`generar_sql(modelo, metrica, por, filtros)`** → el SQL completo de una consulta semántica.

Las funciones `literal` y `consultar` (que ejecuta el SQL con DuckDB) ya están escritas.

Resultado esperado: ingresos netos de 2025 de 45.942.402 € (idénticos a la cuenta de resultados del módulo de finanzas), ticket medio de 284,37 € online y 280,64 € en tienda, y las mismas cifras sumando por canal, por categoría o sin desglose.
