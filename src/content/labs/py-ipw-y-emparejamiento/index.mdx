Implementa cinco funciones usando solo `numpy` y `pandas`:

1. **`simular_observacional(n=20000, seed=0)`** → DataFrame con `x1`, `x2`, `t`, `y` (efecto verdadero de `t` = 1,0).
2. **`propension(df, covariables=("x1", "x2"))`** → array con la probabilidad estimada de tratamiento (regresión logística por Newton-Raphson).
3. **`diferencia_ingenua(df)`**, **`ate_ipw(df, ps)`** y **`att_emparejamiento(df, ps)`** → los tres estimadores del efecto.
4. **`smd(df, columna, pesos=None)`** → diferencia media estandarizada entre tratados y no tratados, con pesos opcionales.

El script imprime los tres efectos y el balance de `x1` antes y después de ponderar.
