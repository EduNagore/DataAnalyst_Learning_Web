Logística quiere un resumen de puntualidad. Clasifica cada envío de `shipments` en una de tres
categorías, según los días entre `promised_date` y `actual_date`:

| `puntualidad`   | regla                       |
| --------------- | --------------------------- |
| `a tiempo`      | retraso de 0 días o menos   |
| `retraso leve`  | entre 1 y 4 días de retraso |
| `retraso grave` | 5 días o más de retraso     |

**Formato del resultado:** una fila por categoría, con las columnas `puntualidad` y `envios`
(número de envíos). Las etiquetas deben escribirse exactamente como en la tabla.
