Parte de la serie diaria de conversión de `exp-checkout-v2` (29 días por rama). Implementa cuatro funciones:

1. **`welch_t(a, b)`** → `(t, gl, p)` del contraste bilateral de Welch para `a` frente a `b`, sin usar `scipy.stats.ttest_ind` (puedes usar `stats.t.sf`).
2. **`tamano_muestra(p1, mde_rel, alpha=0.05, potencia=0.8)`** → entero: clientes necesarios por grupo para detectar un cambio relativo `mde_rel` sobre una proporción base `p1`.
3. **`potencia(p1, mde_rel, n, alpha=0.05)`** → potencia analítica con `n` por grupo.
4. **`potencia_simulada(p1, mde_rel, n, alpha=0.05, n_sim=4000, seed=0)`** → fracción de simulaciones en las que el z de dos proporciones rechaza $H_0$, para comprobar la fórmula.

El script imprime el contraste del experimento, el tamaño de muestra para un +8 % sobre el 5,4 % y la potencia con 10.000 clientes por grupo.
