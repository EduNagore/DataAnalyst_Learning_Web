# Informe con Evidence

Evidence genera un sitio estático a partir de Markdown con consultas SQL.

1. Sigue la guía de inicio de la documentación de Evidence (https://docs.evidence.dev/) para crear el proyecto en esta carpeta.
2. Configura una fuente de datos DuckDB que apunte a `../lumen.duckdb` (esquema `analytics`).
3. Crea una página con KPIs, una tendencia mensual con comparación frente al año anterior y un desglose por región.
4. Cada cifra debe llevar su definición; no calcules en la página lo que ya está en la capa semántica.
5. Configura la publicación en GitHub Pages (ajusta la ruta base del sitio).

Consulta la documentación vigente: los comandos y la configuración cambian entre versiones.
