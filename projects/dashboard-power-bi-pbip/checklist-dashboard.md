# Lista de comprobación del dashboard

## Datos y modelo
- [ ] Modelo en estrella con relaciones uno-a-muchos y filtro del lado «uno» al «muchos».
- [ ] Tabla de fechas continua marcada como tabla de fechas.
- [ ] Claves y columnas técnicas ocultas; medidas explícitas en una carpeta.
- [ ] Cada medida comprobada contra una consulta SQL independiente.

## Diseño
- [ ] La página ejecutiva responde a una decisión; 5-8 indicadores con variación y objetivo.
- [ ] Títulos que dicen la conclusión.
- [ ] Un mensaje por visual; sin 3D ni decoración.
- [ ] Paleta apta para daltonismo; el color no es la única codificación.
- [ ] Definiciones de las métricas visibles (tooltip o página de ayuda) y fecha de actualización.

## Seguridad y operación
- [ ] RLS por región probada con «Ver como».
- [ ] Rendimiento revisado con el Analizador de rendimiento.
- [ ] Proyecto PBIP en Git con mensajes de commit claros.
